# Security

Please do not report a security issue in a public GitHub issue. Use the repository's **Report a vulnerability** button to send it privately to the maintainer. Include the affected version, steps to reproduce, and the impact you observed.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/hweihwang/virtualoffice/issues).
